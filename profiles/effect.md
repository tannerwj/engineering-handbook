# Effect and Effect UI

Effect is an option for TypeScript applications and libraries. It gives teams a shared way to express what an operation returns, how it can fail and which services it needs. The same model supports asynchronous work, concurrency and resource management. [Effect documentation](https://effect.website/)

Effect UI is an option for TypeScript frontends. Components describe their state, the messages that change it and the commands they can run. Teams can use Effect in application code with their existing frontend, or choose Effect UI when they want that model in the interface too. [Effect UI](https://ui.effect.website/)
